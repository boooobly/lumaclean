# Отмена, перенос и закрытие заявки

- В календаре выберите уборку. Над календарём появятся «Перенести уборку» и «Отменить / убрать из календаря». На мобильном эти действия доступны после выбора уборки; в списке дня они находятся рядом с карточкой.
- Перенос открывает существующее планирование с новой датой/временем в Europe/Belgrade. Сохраняется тот же Order, согласованная цена, финансовая история и связь с серией. Расписание каждого клинера, дорога, оборудование и рабочие часы проверяются прежним scheduling service. Конфликт не меняет дату автоматически.
- Отмена требует подтверждения и причины. Она меняет только выбранную уборку на CANCELLED, освобождает её слот и скрывает из активного календаря. Запись БД, финансовые записи, назначения и AuditLog сохраняются. Остальные уборки серии не меняются.
- Для истории включите «Показать отменённые и неявки». Завершённые уборки продолжают отображаться. Отменённую уборку можно повторить через существующую функцию копирования; для обычного переноса сначала отменять заказ не нужно.
- В карточке заказа действия находятся в блоке «Команда и планирование». Завершение выполненной уборки остаётся в существующем блоке изменения статуса с прежними финансовыми проверками.
- В списке заявок и карточке заявки есть отдельная кнопка «Закрыть заявку». Она сохраняет причину и статус LOST; контакты и комментарий остаются. Через «В работу» заявку можно открыть снова. По CONVERTED-заявке отменяется или переносится связанный Order.
- Закрытая владельцем заявка не может автоматически создать заказ через AI. Существующие AI modes не меняются.

Новые диалоги передают updatedAt и отклоняют устаревшее подтверждение. Повторное подтверждение той же отмены/закрытия идемпотентно и не создаёт повторный AuditLog или уведомление. Клинеры получают изменение через прежний Notification worker; отдельный транспорт не добавлен.

Это удаление из активного расписания через отмену с сохранением истории. Безвозвратного удаления заказов и заявок нет. Миграция БД не требуется.
