## Архитектура и анимации

Сохранён один динамический шаблон для пяти услуг и трёх языков. Индивидуальные изображения и alt вынесены в типизированный `serviceVisuals`; коммерческий контент продолжает поступать из прежних модулей. Все стили этапа ограничены `.service-page`.

`ServiceMotion` решает две повторяющиеся задачи: появление содержательных элементов при прокрутке через opacity/transform за 360 мс и раскрытие нативного FAQ за 240 мс. Hover изображений занимает 350–400 мс, ссылок и стрелок — 180–220 мс. Пересчёт высоты выполняется только при пользовательском раскрытии FAQ. Анимация допускает быстрое изменение направления, очищается при уходе со страницы и отменяется при reduced motion. Отменённая анимация удаляется из реестра до запуска следующей: её callback не может восстановить устаревшее состояние при отказе новой анимации. Серверный контент заранее не скрывается; отказ JavaScript или IntersectionObserver не блокирует чтение.
