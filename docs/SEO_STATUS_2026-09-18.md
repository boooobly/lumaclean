## Аналитика

GA4, ресурс 554368271, главная за 11–17 сентября: 3 активных пользователя, 30 событий, 0 ключевых событий. Эти данные могут включать ранние проверки до включения фильтра; это не доказательство наличия трёх клиентов. Реальные заявки в GA4 пока не подтверждены. Тестовые заявки менеджеру не отправлялись.

Исправления:

- Фиксированная метка `utm_source=google&utm_medium=organic&utm_campaign=google_business_profile` распознаётся как `entry_source=google_business_profile`.
- Та же метка сохраняется в источнике заявки для менеджера и принимается API формы.
- Для GA4 передаются только константы campaign_source, campaign_medium, campaign_name; произвольные UTM, имена, телефоны и текст заявок не передаются.
- Для распознанных Google/Yandex/Bing передаётся только безопасный корневой URL поисковика вместо полного referrer. Ранее referrer всегда очищался, что мешало стандартным отчётам об источниках.
- При `analytics_debug=1` внутренний режим сохраняется в пределах вкладки при переходах, в том числе когда параметр пропадает из URL. Начальная конфигурация также получает traffic_type=internal.
- Без согласия аналитика не загружается и источник не сохраняется. Для посетителей без согласия источник следует уточнять у клиента.
- Первая сохранённая страница и источник сохраняются в течение сессии вкладки. Это браузерная атрибуция, а не доказательство причинной связи с заказом.

В настройках Google Business Profile ссылка изменена на:
`https://lumacleanrs.com/sr?utm_source=google&utm_medium=organic&utm_campaign=google_business_profile`

На момент сохранения интерфейс сообщил, что изменение на проверке (обычно до 10 минут). Пока проверка не закончена, нельзя утверждать, что публичная карточка уже использует новую ссылку. Метка различает переходы из карточки компании, которая может отображаться и на Картах, и в обычном поиске.

Реализация использует [официальные параметры Google Analytics](https://developers.google.com/analytics/devguides/collection/ga4/reference/config).
